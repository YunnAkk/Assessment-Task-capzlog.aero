# Glossary

In this document, there is a list of abbreviations used throughout the code and documentation, which might not be self-explanatory.

- `N/A`: Not Available, is used to indicate that a value is missing, unavailable, or not applicable. In a corrupt data field, it signifies that the expected data cannot be retrieved or is unreadable.
- `TTD` : Time-To-Destination
- `enroute`: on route
